## 文件说明

- `index.html`：预览入口，内嵌当前数据，支持直接打开。
- `styles.css` / `app.js`：样式与交互。
- `assets/7.0/`：全部原图，文件名为 `BannerID__APP` 或 `BannerID__小程序`。
- `assets/8.0/`：8.0 新图目录。
- `manifest.json`：完整配置、来源 Excel 行号、图片尺寸及 SHA-256 对照清单。全部 118 个 ID 的 `newImage` 已填写，同 ID 的多个终端共用新版。021～118 记录 `sourceRecordKey` 和 `sourceSha256`，可追溯实际参考原图。

后续替换新版时，按 Banner ID 同步更新该 ID 下全部终端的 `newImage`，各终端原图与配置信息独立保留。更新 `manifest.json` 后需同步 `index.html` 内的 `banner-data`，并更新新版文件 SHA-256 以刷新缓存。
